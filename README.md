# Borderlands 2 Camera

Aparat w przeglądarce ze stylem cel-shaded (kwantyzacja kolorów + czarne kontury) inspirowanym Borderlands 2.

To fanowski filtr wizualny, nie oficjalny produkt Gearbox / 2K. Borderlands jest znakiem towarowym swoich właścicieli.

## Jak odpalić

Kamera działa tylko na HTTPS (albo `localhost`).

1. Otwórz `index.html` na GitHub Pages albo wrzuć plik na dowolny HTTPS.
2. Zezwól na kamerę.
3. REC nagrywa przefiltrowany obraz (WebM). Aparat robi PNG.

Na iPhonie otwórz to w Safari.
